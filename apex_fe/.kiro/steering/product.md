# Product

An admissions CRM connecting three roles: Student, Consultant, Admin.

- Student: submits an inquiry with no login, later checks status with a reference code + email, and uploads documents through that same verification — no separate account.
- Consultant: manages their own assigned students through a six-stage pipeline, logs contact, reviews documents.
- Admin: manages consultants, pipeline configuration, and org-wide reporting.

Tone: a working tool for paid staff, not a marketing site. No exclamation-heavy onboarding, no emoji as UI icons, no generic "Welcome to your dashboard!" filler. Error messages state what actually happened ("That reference code and email don't match any application") not "Something went wrong."
